# T+0 策略回测分析

## 目的

对T+0盯盘系统的多策略评分引擎进行日线级历史回测，评估策略有效性，优化参数阈值，发现哪些策略组合最赚钱。

## 触发条件

- "回测一下策略"
- "分析策略有效性"
- "调优参数"
- "看看哪些策略有用"

## 工作流程

### 1. 运行回测

```bash
cd 回测分析
python T0_strategy_backtest_v2.py
```

回测自动完成：
- 从 westock-data CLI 拉取14只股票近300天日线 OHLCV + MA/RSI 指标
- 对每天评估12条有效策略（已剔除恒真策略）
- 按趋势/波动率分组统计
- 测试多个阈值档位
- 输出到 `回测分析/YYYY-MM-DD-回测/data/backtest-v2.json`

### 2. 分析结果

从 `data/backtest-v2.json` 提取以下维度：

**阈值扫描**：不同阈值(8%-40%)的信号数、胜率、均笔收益、累计收益

**趋势分析**：BULL/BEAR/RANGE环境下的表现差异

**波动率分组**：振幅<2%/2-3%/3-5%/>5%四个档位的胜率和收益

**盘前过滤有效性**：均振幅过滤、趋势过滤等对胜率的提升

**个股排名**：14只股票的胜率、累计收益排行

**策略贡献度**：每条策略的触发频率和区分度

### 3. 生成结论

基于数据分析输出：
- 最优阈值建议
- 应剔除/保留的策略清单
- 适合/不适合做T的个股名单
- 有效的盘前过滤规则

### 4. 应用优化

将结论落实到系统：
- 更新 `t0_monitor.py` 中的 `ALL_STRATEGIES` 默认启用状态
- 调整 `DEFAULT_THRESHOLD`
- 更新 `DEFAULT_EXCLUDED` 排除列表
- 新增 `get_pre_trade_pool()` 盘前过滤规则
- 更新 `strategy-config.json`

## 已知最佳参数（基于2026-05-28回测）

| 参数 | 值 | 说明 |
|------|-----|------|
| 有效策略数 | 12条 | 排除F时间/F非崩/D振幅 |
| 最佳阈值 | 25% | ~3/12条策略满足即触发 |
| 预期胜率 | 70.6% | 阈值25%时 |
| 预期均笔 | +1.59% | 扣费后 |
| 排除股票 | 宁德时代 | 回测胜率24% |
| 盘前振幅过滤 | >2% | 振幅太小无差价 |
| 20日均振幅过滤 | >4% | 历史波动率过低不适合做T |

## 注意事项

- 回测仅用日线OHLC近似模拟T+0，非精确日内P&L
- 数据源：westock-data CLI（`kline` + `technical`）
- 命令行编码：Windows GBK终端不支持emoji，print需用纯文本
- 回测约需1-2分钟（14只股票 × 2次CLI调用）
